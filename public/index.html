HOW TO PLAY

CONTROLS

PC: WASD (Player 1) / Arrow Keys (Player 2)

Mobile: On-screen D-pad

GAME MODES

Play Online — Auto-match with a random opponent

vs AI — Battle the computer (3 difficulties)

Create Room — Start a private room & share the code

Join Room — Enter a friend's room code to join

Play Local — Two players on the same device

SCORING

Each player starts with 30 points and length 3.

Eat food pellets: +10 points, +1 length

Bite self or opponent: -10 points, -1 length to bitten snake

Head-on collision: both snakes take damage

WIN / LOSE

A snake is eliminated when its score drops to 0 or below.

Last snake standing wins.

If both/all are eliminated simultaneously: DRAW.

GAME MODES

Sudden Death: Walls start shrinking after 10 seconds. Touching them deals damage!

Last Man Standing: Online only (3-4 players). No points for biting—just survive the chaos until only one remains.
